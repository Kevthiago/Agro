# 🌱 Agropecuária Santos

[🔗 Acesse o site](https://kevthiago.github.io/Agro/)

Este é um **projeto acadêmico** de site institucional fictício para a *Agropecuária Santos*, desenvolvido utilizando apenas **HTML**, **CSS** e pequenas interações com **JavaScript**. O projeto visa simular a presença online de uma agropecuária, oferecendo uma navegação simples e informativa.

> ⚠️ Este site é apenas para fins educacionais e **não representa oficialmente** a empresa mencionada.

---

## 🎯 Objetivo do Projeto

- Desenvolver um site institucional estático e responsivo  
- Praticar conceitos básicos de HTML e CSS  
- Aplicar organização de conteúdo e navegação entre páginas  
- Simular uma experiência de compra simples, com login e carrinho

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript** (apenas para interações leves)
- **GitHub Pages** (deploy)

---
