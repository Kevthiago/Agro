# 🌱 Agropecuária Santos

[🔗 Acesse o site](https://kevthiago.github.io/Agro/)

Este é um **projeto acadêmico** de site institucional fictício para a *Agropecuária Santos*, desenvolvido utilizando apenas **HTML**, **CSS** e pequenas interações com **JavaScript**. O projeto visa simular a presença online de uma agropecuária, oferecendo uma navegação simples e informativa.

> ⚠️ Este site é apenas para fins educacionais e **não representa oficialmente** a empresa mencionada.

---

## 🎯 Objetivo do Projeto

- Desenvolver um site institucional estático e responsivo  
- Praticar conceitos básicos de HTML e CSS  
- Aplicar organização de conteúdo e navegação entre páginas  
- Simular uma experiência de compra simples, com login e carrinho

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript** (apenas para interações leves)
- **GitHub Pages** (deploy)

---

## 📄 Páginas Disponíveis

| Página | Descrição |
|--------|-----------|
| [Página Principal](https://kevthiago.github.io/Agro/) | Apresentação da empresa, produtos, localização e formas de contato. |
| [Login/Cadastro](https://kevthiago.github.io/Agro/login.html) | Simulação de login e cadastro de usuário. |
| [Carrinho de Compras](https://kevthiago.github.io/Agro/carrinho.html) | Visualização do carrinho, endereço, resumo do pedido e simulação de pagamento. |

Este projeto foi desenvolvido como parte de um trabalho da faculdade de Ciência da Computação, pela disciplina de Programação Web, com o intuito de aplicar conhecimentos introdutórios de desenvolvimento web.
